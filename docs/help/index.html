Glow help

If something here doesn't match your TV, open an issue with your TV or box model.

The Home button still opens the old home screen

Glow catches the Home button with an Android accessibility service. Open Glow setup (bottom of Glow's home screen) and check that Open Glow with the Home button says On ✓.

The switch is greyed out, says "Restricted setting", or turns itself off again. Android 13 and newer block accessibility for apps installed from a file (for example with Downloader). To allow it:

  1. Go to Settings › Apps › See all apps › Glow (Glow setup's App info button opens this page).
  2. Look for Allow restricted settings. On some models it is in a ⋮ menu at the top. Select it.
  3. Go back to Glow setup and turn the Home button on again.

No "Allow restricted settings" anywhere? Some Google TV models (such as the Google TV Streamer) don't show it. It can be allowed once from a computer on the same Wi-Fi, with Android's free platform tools:

  1. On the TV, turn on Settings › System › About › Android TV OS build (select it seven times), then Settings › System › Developer options › USB debugging (on some models, Wireless debugging).
  2. Find the TV's IP address in Settings › Network & Internet.
  3. On the computer, run these, replacing the address with your TV's. Accept the prompt that appears on the TV.
adb connect 192.168.1.50:5555
adb shell appops set app.glowhome.tv ACCESS_RESTRICTED_SETTINGS allow
adb shell settings put secure enabled_accessibility_services app.glowhome.tv/app.glowhome.tv.HomeButtonService
adb shell settings put secure accessibility_enabled 1

You can turn developer options off again afterwards.

Amazon Fire TV. Fire TV doesn't let any other home screen take the Home button. Open Glow from Your apps instead.

Some TV boxes have a Default home app page (Glow setup shows a button for it). Choosing Glow there is all you need.

Arranging apps

On Glow's home screen, select an app and hold OK (or press Menu). Choose Move, use ◀ ▶ to carry it, then press OK. Each mode (Kids, Movie night, Gaming, Music) keeps its own order. Hide from home removes an app from the row; Glow setup › Show hidden apps brings them back.

Screensaver and wallpaper

Select the Screensaver card on the home screen. You can pick the photos (landscapes, cities, nature, night sky or your own), when the screensaver starts, how often the photo changes, and whether the home wallpaper changes every hour or every day.

My photos shows pictures stored on the TV or on a plugged-in USB drive. Glow asks for permission to see them the first time.

Updating

When a new version is out, ⬆ Update to Glow … appears at the top of the home screen. Select it, then Update now. The first time, Android asks you to allow Glow to install apps: switch it on, press Back and select Update now again. Android then shows its own screen to confirm the update. Your settings are kept.
