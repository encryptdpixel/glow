A calm, beautiful home screen for Android TV and Google TV. Free, no ads, no account.

Install or update on your TV

  1. Get Downloader. On the TV, open Google Play, search for Downloader (by AFTVnews) and install it.
  2. Let Downloader install apps. Go to Settings › Apps › Security & restrictions › Unknown sources and switch on Downloader. On many Google TV models this menu only appears after you turn on developer options: go to Settings › System › About and select Android TV OS build seven times.
  3. Download Glow. Open Downloader, type encryptdpixel.github.io/glow/apk and select Go, then Install. To update later, do the same: your settings are kept.
  4. If Play Protect warns you about an unknown developer, select More details › Install anyway. Glow isn't on Google Play, so Play Protect doesn't know it yet.
  5. Open Glow from your apps and follow its setup screen.

Setting up

Glow's setup screen explains three optional switches before you turn them on: Notification access (to show what's playing; your notifications are never read or kept), Usage access (for "Recently watched") and an accessibility service, used only so the remote's Home button opens Glow. It doesn't read the screen, see what you type or collect any data. Some TV makers block the Home button for other home screens; there you can still open Glow from your apps.

Privacy

No accounts, ads, analytics or tracking. What Glow knows about you stays on your TV. Read the privacy policy.
